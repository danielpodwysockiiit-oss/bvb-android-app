BVB APP – STARTPAKET FÜR WINDOWS / VS CODE

Dieses ZIP enthält einen testbaren Browser-Prototyp mit BVB-inspiriertem Design.
Es enthält KEINE fertige APK und keine Live-Bundesliga-Daten. Dafür sind ein API-Anbieter
und eine Android-Build-Umgebung nötig. Android Studio als IDE ist optional, die Android
Build-Werkzeuge sind zum lokalen Erstellen einer APK jedoch erforderlich.

START:
1. ZIP entpacken, z.B. nach C:\BVB-App.
2. Doppelklick auf starten.bat oder index.html.
3. Die Oberfläche läuft im Browser. Tabellen-/Spielplandaten sind Platzhalter, damit keine
   falschen Live-Ergebnisse angezeigt werden.
4. docs\APK_OHNE_ANDROID_STUDIO.txt erklärt die realistischen nächsten Schritte.
